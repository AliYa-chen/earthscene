# 依赖与维护脚本清理

2026-10-20 对 `src/`、`examples/`、构建配置、`actions/` 和 `scripts/` 的模块引用与命令入口进行核对。

## 已删除

- `dotenv`、`tencentcloud-sdk-nodejs-cdn`、`wrangler`：独立项目没有使用这些包的部署代码，原命令仅输出“未配置”并退出。
- 直接开发依赖 `esbuild`：当前脚本没有直接导入或调用它。Vite 自身仍通过依赖链使用 esbuild。
- `actions/deploy.js`、`release.js`、`release-finish.js`、`github-release.js`、`refreshCDN.js` 和空配置模板：均为已禁用流程的占位文件。
- `.agents/skills/deploy` 与 `.agents/skills/release`：同样只剩禁用提示，已删除。
- 对应的 `deploy`、`prepublishOnly`、`release`、`release:patch`、`release:minor`、`release:major` 命令，避免维护悬挂入口。

`release:check` 保留为本地检查命令；包继续标记 `private: true`。GitHub 仓库、官网地址与 npm 发布是独立事项，此次没有启用 npm 发布或网站部署。

## 保留依据

- Three.js、Cesium、3D Tiles、大气/云、后处理与 BVH 相关包：库源码或已有公开类型实际使用。
- Spark、草地/树木、Leva、Monaco、矢量瓦片、`workerpool`：现有示例与 Sandcastle 使用。
- `playwright`：HISM 浏览器基准脚本使用。
- `msdf-bmfont-xml`：文字图集生成脚本使用。
- Vite、VitePress、Vitest、TypeScript、类型包、`concurrently`、`rimraf`、Husky、commitlint：对应构建、开发、测试或提交检查命令仍存在。
- 可选 peer 与公开导出未因仓内缺少直接调用而删除。

## 验证

- `pnpm install --lockfile-only --ignore-scripts` 更新依赖锁。
- `pnpm install --offline --frozen-lockfile --ignore-scripts` 确认锁文件可复现并清除本地无用依赖。
- 剩余 JavaScript 维护脚本全部通过 `node --check`，`package.json` 的 Node 命令均指向存在的文件。
- 全量类型检查、测试与库/站点构建由本轮整体清理统一执行。
