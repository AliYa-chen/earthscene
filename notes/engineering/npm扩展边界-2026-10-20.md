# npm 扩展入口与宿主边界

npm 默认入口 `earthscene` 与 `earthscene/cesium` 只导出 `ESClouds`、`ESPluginHost`、`esClouds`、`ES` 及对应类型。完整 Three.js 引擎单独在 `earthscene/engine`，现有源码示例仍从 `../src` 导入。

`ESPluginHost` 只接收已经存在的 Cesium Viewer，不创建、不销毁它。云插件不覆盖方法、修改原型或设置全局默认值；只注册自己的后处理和事件监听器，销毁只移除自己拥有的资源。质量切换只调采样次数，保持原有后处理顺序；正交相机保持原状并禁用此透视效果。

2026-10-20 验证：443 项自动测试通过，类型/库构建通过，独立 npm 消费项目运行导入与 TypeScript 检查通过。真实 Cesium WebGL 页面在云前后安装两个使用方后处理，质量切换保持顺序；销毁云宿主后两个后处理、原生 Viewer、相机、时钟、地形、影像和场景配置保持有效，未出现浏览器异常。

这些检查覆盖当前版本的接口与已测共存场景，不保证所有第三方 shader 或硬件的视觉效果一致；启用效果会正常产生GPU开销。
